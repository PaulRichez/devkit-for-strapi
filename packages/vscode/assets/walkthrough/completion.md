# Write Strapi calls with completion

Type a Strapi call — `strapi.documents('`, `strapi.service('`, a route `handler`, a `policies` entry — and DevKit suggests the real names of *your* project.

A name that doesn't exist is underlined, with a fix when a close one does. Hover a name to see what it resolves to; **Go to Definition** opens it; **Find All References** lists every call-site, magic strings included.

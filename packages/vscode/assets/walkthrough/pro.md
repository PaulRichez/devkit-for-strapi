# Refactor safely with Pro

With a Pro licence, refactor from where you see things:

- **F2** on a Strapi name renames it everywhere — magic strings and route handlers included.
- From the panel: rename a content-type, a component, a field or a controller action, retarget a relation, move a content-type into a plugin, scaffold a plugin.

Every refactor first lists what it doesn't do (the UIDs Strapi stores in the database, for one), then opens VS Code's **Refactor Preview**: nothing is written until you apply it.

The views stay free.

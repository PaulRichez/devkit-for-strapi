# Give your AI agent the same knowledge

DevKit ships an MCP server: your agent queries the project instead of guessing UIDs, routes or plugin names.

- **GitHub Copilot (agent mode)** finds it automatically: it's registered by this extension.
- **Claude Code, Cursor, Windsurf…** — add the `devkit-for-strapi-mcp` server; the setup for each client is on the [MCP page](https://devkit-for-strapi.paulrichez.fr/mcp/).
